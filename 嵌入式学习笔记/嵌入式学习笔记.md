## GPIO

### GPIO四大寄存器：CRL/CRH/IDR/BSRR

#### CRL、CRH：

##### 设置引脚模式（输出/输入/开漏/推挽

```设置引脚模式（输出/输入/开漏/推挽
CRL/CRH
操作 PA6 → 清空代码固定写：GPIOA->CRL &= ~(0xF << 24);
操作 PA0 → 清空代码固定写：GPIOA->CRL &= ~(0xF << 0);
（其他引脚：PAx → 0xF << (x×4)）

每个引脚占4个二进制为

IDR（Input Data Register，输入数据寄存器）
    只读：0 低电平 1 高电平
    寄存器位    0~15 位（低 16 位）    16~31 位（高 16 位）
    作用    对应 GPIO 引脚的实时输入电平（只读！）    保留位（无意义，永远为0）
    人话    「电平检测区」：读某一位的值，就能知道对应引脚当前是高电平还是低电平
    核心特点    只读寄存器 → 只能用「读」操作（GPIOA->IDR），
                不能写（比如 GPIOA->IDR = 1 << 6; 是错误的）
    GPIOA -> IDR &(1 << 0) 读取PA0的电平

BSRR
    寄存器位    0~15 位（低 16 位）    16~31 位（高 16 位）
    作用    置 1 → 引脚输出高    置 1 → 引脚输出低
    人话    点灯区    灭灯区

    GPIOA->BSRR = 1 << 6; → 亮
    GPIOA->BSRR = 1 << (6+16); → 灭
    本质是：BSRR 寄存器分上下两半，上半区灭灯，下半区点灯
```

GPIOA ->CRL |=(0x3 << 24)  (推挽输出)

STM32 规定了 GPIO 引脚的配置规则：每个引脚的 4 位里，前 2 位管 “速率”，后 2 位管 “模式”。
     0x3 = 二进制 0011
    前 2 位 00 → 50MHz 输出速率（最快，新手无脑用）
    后 2 位 11 → 通用推挽输出模式（点灯最常用）

##### ODR 反转电平

// 反转PA6的电平

GPIOA -> ODR ^= (1<<6);   

### GPIO配置流程：

### 先清空--->再配置--->精准控制

✅ RCC 开时钟：RCC->APB2ENR |= 1 << 2;（给 GPIOA 供电）
✅ GPIO 配置流程：先清空（&= ~(0xF << 24)）→ 再配置（|= 0x3 << 24），精准控制 PA6 为输出模式
✅ BSRR 控电平：低 16 位第 n 位点灯（1<<n）、高 16 位第 n 位灭灯（1<<(n+16)），引脚和位号严格对应

上拉电阻：给引脚设置一个默认电平，避免悬空时电平乱跳（漂移）
    常用在：
    1. 所有「机械按键 / 开关」输入
    2. I2C 总线通信（必备）
    3. SPI 总线（可选）
    4.  UART 串口（可选）
    5.  传感器输入引脚

#### 按键配置四步走：

    1.开始时钟：RCC->PAB2ENR |=1<<2;(PA0引脚，开GPIOA的时钟)
    2.清空对应4位：GPIOA->CRL &=~(0xf << 0);
    3.设为上拉输入：GPIOA->CRL &=~(0x8 << 0);
    4.开上拉电阻：GPIOA->ODR |=(1 << 0);
        ODR 是32位寄存器，分高16位，低16位，高的是上拉电阻，低的是下拉电阻，对应引脚号（上拉：PA1 （1<<1）下拉 PA1（1<< (1+16)））

推挽：自己能出高电平 → 点灯用
开漏：自己出不了高电平 → 通信用

## 按键控制LED灯亮灭案例：

##### 实现的功能是： 按键控制灯亮灯灭

```textplane
接线：
LED 正极 -》 PA6
按键一段 -》 PA0

另一端都接 GND
```

```c
//main

// init

// 要用外设 先开时钟
RCC -> APB2ENR |= 1<<2;
// 先清除原有配置 PA6 PA0
GPIOA -> CRL &=~(0xF << 24); // PA6

GPIOA -> CRL &=~(0xF << 0);  // PA0

// 配置引脚 配置PA6为输出模式 PA0 上拉输入
GPIOA -> CRL |= (0x3 << 24);  // PA6
GPIOA -> CRL |= (0x8 << 0);  // PA0

// 开启PA0的上拉电阻
GPIOA -> ODR |= (1<<0);


//while

// 判断按钮是否按下
if((GPIOA -> IDR &(1 << 0)) == 0){
    HAL_Delay(20); // 按键消抖
    // 再次判断按钮是否按下
    if((GPIOA -> IDR &(1 << 0)) == 0){
        // BSRR 设置引脚为低电平 
        GPIOA -> BSRR = 1<<6;
        HAL_Delay(1000);
        while((GPIOA -> IDR &(1<<6)) != 0);
}else{
    GPIOA -> BSRR = 1 << (6+16);
}

}
```

## 中断

### 外部中断开发核心流程：

#### 1.开启外设时钟

```c
// 1. 开启 GPIOA 时钟（PA4/PA5 属于 GPIOA 外设）
RCC -> APB2ENR |= 1 << 2;
// 2. 开启 SYSCFG 时钟（中断复用功能必须开，EXTI 依赖它）
RCC -> APB2ENR |= 1 << 0;
```

#### 2.配置GPIO引脚

#### volatile

    **告诉编译器：“这个变量的值随时可能被硬件或中断改变，你每次用到它时都必须老老实实从内存里重新读，不许偷懒用缓存的值。”**

    **凡是中断里会改、主循环里会读的变量，加 `volatile`。凡是没加 `volatile` 却出现了“明明改了对面的值，但这边就是看不到”的灵异现象，先怀疑是不是漏了 `volatile`。**

```c
//  清空 PA4/PA5 原有配置（避免旧配置干扰）
GPIOA -> CRL &= ~(0xF << 20); // PA5
GPIOA -> CRL &= ~(0xF << 16); // PA4
// 2. 配置 PA4 为「上拉输入」（按键中断输入）
GPIOA -> CRL |= (0x8 << 16);
// 3. 配置 PA5 为「推挽输出」（LED 控制）
GPIOA -> CRL |= (0x3 << 20);
// 4. 开启 PA4 上拉电阻（按键默认高电平，按下接地为低）
GPIOA -> ODR |= (1 << 4);
```

#### 3.映射中断线到GPIO引脚

```c
// 1. 清空 EXTI4 原有映射配置
AFIO -> EXTICR[1] &=~(0xF << 0);
// 2. 将 EXTI4 映射到 GPIOA（0x0 对应 GPIOA，0x1=GPIOB...）
AFIO -> EXTICR[1] |= (0x0 << 0);
```

#### 4.配置EXTI中断控制器（触发方式+使能）

```c
// 1. 开启 EXTI4 中断（解除屏蔽）
EXTI -> IMR |= 1<<4;
// 2. 设置下降沿触发（按键按下时，PA4 从高→低触发）
EXTI -> FTSR |= 1<<4;
```

#### 5.配置NVIC（中断优先级+使能）

```c
// 1. 开启 EXTI4 中断通道
NVIC_EnableIRQ(EXTI4_IRQn);
// 2. 设置中断优先级（数字越小优先级越高）
NVIC_SetPriority(EXTI4_IRQn, 5);
```

#### 6.编写中断服务函数（函数名是固定的）

```c
void EXTI4_IRQHandler(void){
  // 第一步：清除中断挂起标志（必须！否则会无限触发中断）
  EXTI->PR |= 1 << 4;

  // 第二步：按键消抖（极简延时，避免机械抖动误触发）
  for(int i=0; i<100; i++);

  // 第三步：判断中断源有效性（确认是按键按下）
  if((GPIOA->IDR & (1<<4)) == 0)
  {
    // 第四步：执行业务逻辑（翻转 LED）
    GPIOA->ODR ^= (1<<5);
    // 第五步：等待按键松开（防止重复触发）
    while((GPIOA->IDR & (1<<4)) == 0);
  }
}
```

   中断是指 CPU 在执行程序的过程中，出现内部或外部随机发生的紧急事件时，
暂停当前正在执行的程序，转去执行处理该事件的专用程序（中断服务函数），
处理完成后再返回到原来被暂停的位置继续执行的过程。

### 🧪 对照实验：PA4 → PA3（中断线 4 → 3）

| 步骤               | 原来（PA4，EXTI4）                                                                                     | 改后（PA3，EXTI3）                                                                                      | 改动原因                              |
| ---------------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------- |
| **1. 开启时钟**      | `RCC->APB2ENR \|= 1<<2;`（GPIOA）<br>`RCC->APB2ENR \|= 1<<0;`（SYSCFG）                               | **完全相同，不改**                                                                                        | 还在 GPIOA，时钟不变                     |
| **2. GPIO 配置**   | `GPIOA->CRL &= ~(0xF << 16);`（PA4）<br>`GPIOA->CRL \|= (0x8 << 16);`<br>`GPIOA->ODR \|= (1 << 4);` | `GPIOA->CRL &= ~(0xF << 12);`（PA3）<br>`GPIOA->CRL \|= (0x8 << 12);`<br>`GPIOA->ODR \|= (1 << 3);`  | **移位量变**：PA3 是第 3 个引脚，`4×3=12`    |
| **3. 映射中断线**     | `SYSCFG_EXTICR2 &= ~(0xF << 0);`<br>`SYSCFG_EXTICR2 \|= (0x0 << 0);`                              | **寄存器变**：EXTI3 在 EXTICR1<br>`SYSCFG_EXTICR1 &= ~(0xF << 12);`<br>`SYSCFG_EXTICR1 \|= (0x0 << 12);` | EXTI3 在 EXTICR1 的 bit 12-15       |
| **4. EXTI 触发配置** | `EXTI->IMR \|= 1<<4;`<br>`EXTI->FTSR \|= 1<<4;`                                                   | `EXTI->IMR \|= 1<<3;`<br>`EXTI->FTSR \|= 1<<3;`                                                    | **中断线编号变**：4 → 3                  |
| **5. NVIC 配置**   | `NVIC_EnableIRQ(EXTI4_IRQn);`<br>`NVIC_SetPriority(EXTI4_IRQn, 5);`                               | `NVIC_EnableIRQ(EXTI3_IRQn);`<br>`NVIC_SetPriority(EXTI3_IRQn, 5);`                                | **中断通道变**：EXTI4_IRQn → EXTI3_IRQn |
| **6. 中断服务函数**    | `void EXTI4_IRQHandler(void)`                                                                     | `void EXTI3_IRQHandler(void)`                                                                      | **函数名变**                          |
| **6. 函数内部**      | `EXTI->PR \|= 1<<4;`<br>`if((GPIOA->IDR & (1<<4))==0)`<br>`while((GPIOA->IDR & (1<<4))==0);`      | `EXTI->PR \|= 1<<3;`<br>`if((GPIOA->IDR & (1<<3))==0)`<br>`while((GPIOA->IDR & (1<<3))==0);`       | 所有 `4` 改成 `3`                     |

### 中断执行流程：

    1.中断发生(按键按下/定时器时间到)（中断请求）
    2.暂停主程序（中断响应）
    3.执行中断服务程序(专门处理中断的函数)（中断处理）
    4.处理完，回到主程序继续执行（中断返回）

### 中断线（EXTI）与 GPIO 引脚的绑定规则：

    stm32有16条外部中断线（EXTI0---EXTI15）:
        STM32F103 的 EXTI 中断通道与 GPIO 引脚的映射规则是：
            EXTI0_IRQn → PA0/PB0/PC0/PD0...（所有端口的 0 号引脚）
            EXTI1_IRQn → PA1/PB1/PC1/PD1...
            ...
            EXTI4_IRQn → PA4/PB4/PC4/PD4...
            EXTI9_5_IRQn → PA5~PA9、PB5~PB9、PC5~PC9...（5~9 号引脚共用一个中断通道）
            EXTI15_10_IRQn → PA10~PA15、PB10~PB15...（10~15 号引脚共用一个中断通道

### 外部中断的三大配置步骤:

    1.配置GPIO的输出模式为：输入模式
        让引脚能检测电平变化
    2.配置EXTI中断线
        1.把GPIO引脚线绑定到对应的中断线
        2.设置触发方式
    3.配置NVIC
        开启cpu对这个中断的权限，设置优先级

### 关键寄存器：

#### 1.AFIO时钟（RCC->APB2ENR |= 1 << 0;）

        功能：AFIO是“GPIO复用功能时钟”，EXTI引脚绑定必须要用这个时钟
        操作代码： 开启：RCC->APB2ENR |= 1 << 0;

#### 2.SYSCFG->EXTICR (中断线--引脚绑定寄存器)

```c
#define SYSCFG_BASE 0x40011000 // SYSCFG外设基地址
#define SYSCFG_EXTICR2 *(volatile uint32_t *)(SYSCFG_BASE + 0x08)  
```

STM32 用 **4 个 32 位寄存器** 来管理 **16 条中断线（EXTI0 ~ EXTI15）**。

每个寄存器刚好管理 4 条中断线，每条线占 **8 位**（但实际只用低 4 位）。

| 寄存器类型              | 例子                                    | 每条线占几位  | 偏移规律           |
| ------------------ | ------------------------------------- | ------- | -------------- |
| **配置型**（一个寄存器管多条线） | `SYSCFG_EXTICR1`                      | **4 位** | 中断线号 × 4       |
| **位掩码型**（每一位就是一条线） | `EXTI->IMR`, `EXTI->FTSR`, `EXTI->PR` | **1 位** | 中断线号 × 1（即不移位） |

```c
// 1. 开启 EXTI4 中断（解除屏蔽）
EXTI -> IMR |= 1<<4;
// EXTI5
// EXTI -> IMR |= 1<<5;
// 2. 设置下降沿触发（按键按下时，PA4 从高→低触发）
EXTI -> FTSR |= 1<<4;
```

| 寄存器名称       | 地址偏移 | 管理的中断线（EXTIx）                      |     |
| ----------- | ---- | ---------------------------------- | --- |
| **EXTICR1** | 0x00 | **EXTI0, EXTI1, EXTI2, EXTI3**     |     |
| **EXTICR2** | 0x08 | **EXTI4, EXTI5, EXTI6, EXTI7**     |     |
| **EXTICR3** | 0x10 | **EXTI8, EXTI9, EXTI10, EXTI11**   |     |
| **EXTICR4** | 0x14 | **EXTI12, EXTI13, EXTI14, EXTI15** |     |

功能：指定 “哪一个 GPIO 的 x 号引脚” 绑定到 EXTIx 中断线
寄存器拆分：
    SYSCFG 有 4 个 EXTICR 寄存器（EXTICR1~EXTICR4），对应 EXTI0~EXTI15：
        EXTICR1 → EXTI0~EXTI3
        EXTICR2 → EXTI4~EXTI7
        EXTICR3 → EXTI8~EXTI11
        EXTICR4 → EXTI12~EXTI15

        EXTI9_5_IRQn → PA5~~PA9、PB5~~PB9、PC5~~PC9...（5~~9 号引脚共用一个中断通道）
        EXTI15_10_IRQn → PA10~~PA15、PB10~~PB15...（10~15 号引脚共用一个中断通道  每4位控制1条中断线（比如EXTICR1的0-3）
    4 位数值    对应 GPIO 端口    举例（EXTI0）
    0000    PA    EXTI0 绑定 PA0
    0001    PB    EXTI0 绑定 PB0
    0010    PC    EXTI0 绑定 PC0
    0011    PD    EXTI0 绑定 PD0
代码操作：
    SYSCFG->EXTICR1 &= ~(0xF << 0); // 先清空EXTI0的4位（0~3位）
    //为什么先清空：避免寄存器原有值干扰，和 GPIO 配置 “先清后配” 逻辑一致
    SYSCFG->EXTICR1 |= (0x0 << 0);  // 写入0000，绑定PA0

### 3.EXTI->IMR(中断屏蔽寄存器)

功能：决定 “是否允许某条中断线发出中断请求”；
操作代码：开启EXTI0：EXTI->IMR |= 1<<0;
    IMR 寄存器的第 0 位对应 EXTI0，置 1 = 允许 EXTI0 发请求，置 0 = 屏蔽（即使按键按了，也不发请求）；

#### 4.EXTI->FTSR/RTSR (触发方式寄存器)

   功能：设置中断的触发条件（电平变化方式）；
        FTSR（Falling Trigger）：下降沿触发 → 电平从高→低（按键按下，上拉模式下 PA0 从 1→0）；
        RTSR（Rising Trigger）：上升沿触发 → 电平从低→高（按键松开，PA0 从 0→1）；
    操作代码（EXTI0 下降沿触发）：
        EXTI->FTSR |= 1 << 0;
    为什么选下降沿：
        上拉模式下，按键松开时 PA0 是高电平（稳定），按下时是低电平（稳定），下降沿对应 “按下动作”，比上升沿更不容易受抖动干扰。

#### 5.NVIC（嵌套向量中断控制器）

1.NVIC->ISER(中断使能寄存器)
    功能：
        开启 CPU 对某个中断的响应权限；
    中断编号：
        STM32 每个中断都有唯一编号（查手册可得），比如：
            EXTI0 → 中断编号 6
            EXTI1 → 中断编号 7
            EXTI2 → 中断编号 8
    操作代码（开启 EXTI0）：
        NVIC->ISER[0] |= 1 << 6;
        ISER [0] 对应中断编号 0~31，ISER [1] 对应 32~63，EXTI0 是 6，所以操作 ISER [0] 的第 6 位；
2.NVIC->IP (中断优先级寄存器)
    功能：
        设置中断的优先级（数字越小，优先级越高）；
    操作代码（EXTI0 优先级设为 0）：
        NVIC->IP[6] = 0x00;
        IP 寄存器的索引对应中断编号（6=EXTI0）；
        STM32 优先级分 “抢占优先级” 和 “响应优先级”，初学直接设为 0（最高）即可，不用拆分。

#### 6.EXTI->PR(中断挂起寄存器)

    功能：
        标记 “某条中断线是否有未处理的中断请求”；
    核心特点：
        中断触发后，PR 对应位会自动置 1；如果不手动清 0，CPU 会一直认为 “中断没处理完”，反复触发中断服务函数；
    清除代码（EXTI0）：EXTI->PR |= 1 << 0;
        PR 寄存器是 “写 1 清 0”（特殊！大多数寄存器是写 0 清 0），必须置 1 才能清除标志位。

##### 中断函数的“铁律”：

     1.函数名必须固定：
        STM32 规定了每个中断对应的服务函数名，比如 EXTI0 的函数名是EXTI0_IRQHandler（错一个字母都不行）；→ 可以查 STM32 启动文件（startup_stm32f103xx.s），里面列了所有中断函数名。
    2.必须做的三件事：
        1.检查中断标志位（确认EXTI0触发，避免误处理）
        2.处理业务逻辑
        3.清除中断标志（必须，否则反复触发）
            void EXTI0_IRQHandler(void)
                {
                    // 1. 检查中断标志位（确认是EXTI0触发，避免误处理）
                    if(EXTI->PR & (1 << 0)) 
                    {
                        // 2. 处理业务逻辑（比如翻转LED）
                        // ...
                        // 3. 清除中断标志位（必须！否则反复触发）

## 串口

#### 最基础的串行通信协议

#### 基本定义

- **异步串行通信**：无需时钟线，仅靠 TX（发送）、RX（接收）、GND（共地）3 根线通信
- **全双工**：TX/RX 独立，可同时发 / 收数据（对比半双工：同一时间只能发或收）
- **电平标准**：STM32 用 TTL 电平（高 = 3.3V=1，低 = 0V=0），和 RS232（高 =-12V=0，低 =+12V=1）需电平转换

#### 串口通信必须约定 3 件事：

| 约定项  | 说明              | 新手推荐值                    |
| ---- | --------------- | ------------------------ |
| 波特率  | 每秒传输的位数（语速）     | 9600 / 115200（最常用）       |
| 帧格式  | 数据位 + 校验位 + 停止位 | 8N1（8 位数据 + 无校验 + 1 位停止） |
| 电平标准 | 电信号对应的逻辑值       | STM32 TTL（3.3V）          |

#### 

### DR 其实是 “两个房间共用一个门牌号”

- **写 DR → 进入** 发送数据寄存器 TDR
- **读 DR → 来自** 接收数据寄存器 RDR

复制数据

strcpy(data, (char*)uart1_recv_buf);

#### 为什么串口乱码？

波特率不一致（最常见）
数据位 / 停止位配置不一样
硬件接线错（TX 接 TX、RX 接 RX，应该交叉接）

#### 为什么收不到数据？

    没开接收使能（RE 位）
    没接 GND（串口需要共地）
    电平不匹配（比如 STM32 TTL 接 RS232 没转电平

### 一、通用定时器是什么？

在 STM32（最常用的嵌入式 MCU）中，**通用定时器**（TIM2~TIM5、TIM9~TIM14 等）是一种可编程的硬件计时 / 计数外设，简单理解就是：

- 它是 MCU 内部的「精准闹钟」：能按你设定的时间触发事件（比如每隔 1ms 执行一次函数）；
- 它是「计数器」：能统计外部信号的脉冲数（比如统计编码器的脉冲）；
- 它是「PWM 发生器」：能输出精准占空比的方波（驱动舵机、呼吸灯的核心）；
- 核心优势：**硬件自动运行，不占用 CPU 资源**（比软件延时（`delay()`函数）精准 100 倍，且不卡程序）

### 二。 通用定时器的核心定位

- 本质：STM32 内部的**硬件计时 / 计数外设**，核心优势是「精准、不占用 CPU 资源」（区别于软件延时）；
- 核心用途：精准延时、脉冲计数、生成 PWM

### 三。 架构核心三要素（怎么算定时周期）

这是新手必须掌握的「公式级」知识点，所有定时 / 分频配置都围绕这三个参数：

### 计数频率 = 输入时钟 / (PSC + 1)

### 定时周期 T = (PSC + 1) × (ARR + 1) / 输入时钟频率（比如 72MHz）

| 核心部件                 | 英文缩写             | 作用                      | 关键公式                                              |
| -------------------- | ---------------- | ----------------------- | ------------------------------------------------- |
| <mark>预分频器</mark>    | <mark>PSC</mark> | 对输入时钟分频，得到「计数时钟」        | 计数时钟 = 输入时钟 / (PSC + 1)                           |
| <mark>自动重装寄存器</mark> | <mark>ARR</mark> | 设定计数器最大值，决定「定时周期」       | 定时周期 T = (PSC + 1) × (ARR + 1) / 输入时钟频率（比如 72MHz） |
| <mark>计数器</mark>     | <mark>CNT</mark> | 按计数时钟累加 / 累减，到 ARR 触发事件 | 向上计数模式：0→ARR→清零，触发「更新事件」（中断 / PWM 的核心触发源）         |

| 寄存器     | 全称       | 作用         | 通俗理解                        |
|:-------:|:--------:|:----------:|:---------------------------:|
| **PSC** | 预分频器     | 对定时器时钟进行分频 | 相当于 “减速齿轮”，把快时钟变慢           |
| **CNT** | 计数器      | 实时计数的寄存器   | 相当于 “秒表的数字显示”，每来一个脉冲加 1     |
| **ARR** | 自动重装载寄存器 | 计数器的最大值    | 相当于 “秒表的上限”，到了这个值就清零（或产生中断） |

> 如果 APB1 分频系数 = 1，定时器时钟 = PCLK1
> 
> 如果 APB1 分频系数 ≥ 2，定时器时钟 = **PCLK1 × 2**

所以：

- TIM2 挂在 APB1 上
- 定时器时钟 TIM2_CLK = 36MHz × 2 = **72MHz** ✔

### 第二步：计算 PSC（预分频器）

我们想要 **1us 计数一次**（即计数频率 = 1MHz）。

定时器时钟输入： 72MHz

公式：

#### **计数频率=（PSC（预分频器）+1）/ 定时器时钟​**

代入已知：

1MHz=（PSC+1）/72MHz​

解得：

PSC=72−1=71

#### **新手必记例子**：**输入时钟 72MHz，想实现 <mark>1ms 定时</mark>**

### 定时周期 T = (PSC （预分频器）+ 1) × (ARR（自动重装载寄存器） + 1) / 定时器时钟

→ PSC=71（分频后计数时钟 1MHz，1μs / 次），ARR=999（计数 1000 次 = 1ms）

→ 验证：(71+1)×(999+1)/72MHz = 72×1000/72000000 = 1ms。

### 什么时候需要加__DSB();？

DSB它是一个**内存屏障指令**，强制内核：

> “必须等前面所有的内存访问（寄存器写入）都**彻底完成、总线确认生效**了，才能执行后面的代码。”

只要是 **“先开外设时钟，再立刻写该外设寄存器”** 的场景，都建议加一个 `__DSB();`，这是一个好习惯。

#### 2.配置定时器时基单元

```c

// 公式：计数频率=（PSC+1）/ 定时器时钟​
```

```c
    // 2.清零计数器，确保从0开始计数
    TIM2 -> CNT = 0;

    while(TIM2 -> CNT < nus);

    // 5.停止计时器
    TIM2 -> CR1 &=~(1 << 0);

}
```

## PWM

### 一.什么是PWM

##### pwm : 脉冲宽度调制

    快速开关电，控制“高电平持续时间”，来模拟不同电压/效果。

### 二.PWM两个最核心概念

#### 1.周期T（Cycle）

               一次完整的“高+低”的总时间

                舵机常用的周期是：20ms = 50Hz

                20ms重复一次波形

#### 2.占空比（Duty）（=比较值 CCR）

            占空比 = 高电平时间 / 总周期

            高电平 1ms 周期T 20ms

            CCR = 占空比：1/20 = 5%

            高电平 1.5ms 周期T 20ms

            占空比：1.5/20 = 0.075 = 7.5%

### 三.定时器怎么生成PWM

#### <mark> ARR 决定周期</mark>

#### 高电平时间由 CCR 决定

      向上计数模式

        1. 计数器从 0 开始往上加

        2.到达一个值（ARR）后清零，重新开始

        3.在计数过程中：

             **计数器 < CCR → 输出高电平**

            **计数器 ≥ CCR → 输出低电平**

#### 配置PWM通用流程

1. 开时钟（GPIO + 定时器 + AFIO）
2. 配置GPIO引脚（复用推挽输出）
3. 复位定时器（清空脏数据）
4. 配置定时器时钟（PSC + ARR = 设定频率）
5. 配置PWM模式（PWM1 + 预装载）
6. 配置通道极性 + 输出使能
7. 触发更新事件（让配置生效）
8. 启动定时器
9. 修改CCR寄存器（设置占空比）

### 1. CCMR1 管 CH1、CH2

- CH1：偏移 **4**
- CH2：偏移 **12**

### 2. CCMR2 管 CH3、CH4

- CH3：偏移 **4**
- CH4：偏移 **12**

### 3. CCER 通道使能

- CH1: 0
- CH2: 4
- CH3: 8
- CH4: 12

### 小知识

TIM2_CH1 默认绑定引脚PA0
TIM2_CH2 默认绑定引脚PA1

```c
{
  // 1. 开时钟 【通用】
  RCC->APB2ENR |= (1 << 2);   // GPIOA 时钟
  RCC->APB1ENR |= (1 << 0);   // 定时器时钟 (TIM2=bit0, TIM3=bit1, TIM4=bit2)
  RCC->APB2ENR |= (1 << 0);   // AFIO 时钟（重映射用，必开）
  __DSB();

  // 2. 配置GPIO 【根据引脚修改】
  // PA6 复用推挽输出 50MHz
  GPIOA->CRL &= ~(0xF << 24);
  GPIOA->CRL |=  (0xB << 24);

  // 3. 复位定时器 【通用】
  RCC->APB1RSTR |=  (1 << 0);
  RCC->APB1RSTR &= ~(1 << 0);

  // 4. 配置定时器频率 【通用，修改PSC/ARR改频率】
  // 示例：72MHz / 72 / 20000 = 50Hz (舵机)
  TIMx->PSC = 71;        // 预分频
  TIMx->ARR = 19999;      // 自动重装载
  TIMx->CR1 |= (1 << 7);  // ARR 预装载使能

  // 5. 配置PWM模式 【通用，仅通道位置不同】
  // 清空对应通道配置
  TIMx->CCMR1 &= ~(0xFF << 0);   // CH1:<<0  CH2:<<8
  // PWM1模式 + 预装载使能
  TIMx->CCMR1 |= (6 << 4);       // CH1:<<4  CH2:<<12
  TIMx->CCMR1 |= (1 << 3);       // CH1:<<3  CH2:<<11

  // 6. 通道极性 + 输出使能 【通用】
  TIMx->CCER &= ~(1 << 1);       // 高电平有效
  TIMx->CCER |=  (1 << 0);       // 通道输出使能

  // 7. 更新配置 【通用】
  TIMx->EGR |= (1 << 0);

  // 8. 启动定时器 【通用】
  TIMx->CR1 |= (1 << 0);

  // 9. 设置初始占空比 【通用】
  TIMx->CCR1 = 1500;  // 舵机中位
}
```

## 一、I2C 基础核心

**I2C**（Inter-Integrated Circuit，集成电路总线）是一种**用于短距离、板内通信的简单两线制串行通信协议**。

1. **硬件特性**
   
   - 2 根线：**SDA (数据线)** + **SCL (时钟线)**
   - 开漏输出，必须外接上拉电阻
   - 半双工通信，多主机 / 多从机架构
   - 标准速率：100kHz，快速速率：400kHz

2. **通信规则**
   
   - 时钟由**主机**控制 SCL 产生
   - 数据在 SCL 高电平时**采样**，低电平时**允许翻转**
   - 所有时序严格遵循：起始→从机地址 + 读写位→ACK→数据→ACK→停止

##### **2 根线 + 2 个电平时序铁律（最重要）**

    **I2C的两个引脚配置成<mark>复用开漏</mark>（0x0F）输出**

```c
/* 2。配置要使用GPIO */
void GPIO_Init(void){
  // 清除原有配置 PA6 PA7
  GPIOB -> CRL &=~(0xF << 24);
  GPIOB -> CRL &=~(0xF << 28);

  // 配置为 复用开漏 
  GPIOB -> CRL |=(0x0F << 24);
  GPIOB -> CRL |=(0x0F << 28);
}
```

1. **SCL = 高电平时，SDA 绝对不能变！**
   
   - 高电平 = 采样数据
   - 变化 = 被当成起始 / 停止信号

2. **SCL = 低电平时，SDA 才能翻转！**
   
   - 低电平 = 准备下一位数据
   - 这是写驱动最容易错的地方

> 口诀：**高读低改**

## 二、I2C 核心时序（纯硬件逻辑，寄存器操作依据）

### 1. 空闲状态

- <mark>SDA、SCL **同时保持高电平**</mark>
- 寄存器操作：GPIO 配置为开漏输出，输出高电平（外部上拉）

### 2. 起始信号（START）【主机发送】

**时序定义**：

SCL 高 SDA 下降沿

<mark>SCL 保持高电平时，SDA**从高电平拉低** → 产生起始信号</mark>

> 这是 I2C 通信开始的标志，所有传输必须以起始信号开头

**纯寄存器操作逻辑**：

1. SCL=1，SDA=1（空闲）
2. SDA=0（拉低数据线）
3. 延时（满足时序要求）
4. SCL=0（拉低时钟，准备传输数据）

### 3. 停止信号（STOP）【主机发送】

**时序定义**：

SCL 高  SDA 下降沿

<mark>SCL 保持高电平时，SDA**从低电平拉高** → 产生停止信号</mark>

> 标志一次 I2C 通信结束

**纯寄存器操作逻辑**：

1. SCL=0
2. SDA=0
3. SCL=1
4. SDA=1（释放数据线）
5. 延时

### 4. 数据传输时序（8 位数据）

**核心规则**：

- SCL=**低电平**：SDA 可以翻转（主机 / 从机更新数据）
- SCL=**高电平**：SDA 数据稳定，**采样读取**
- 先传**最高位 (MSB)**，最后传最低位 (LSB)

**单字节传输步骤**：

1. SCL=0 → 改变 SDA 为第 1 位数据
2. SCL=1 → 采样数据
3. SCL=0 → 改变 SDA 为第 2 位数据
4. 重复 8 次，完成 1 字节传输

### 5. 应答信号（ACK / NACK）

每传输 1 字节（8 位）后，必须跟随**1 位应答信号**：

- **ACK (应答)**：从机拉低 SDA=0 → 表示数据接收成功
- **NACK (非应答)**：从机释放 SDA=1 → 表示接收失败 / 通信结束

**主机接收 ACK 逻辑**：

1. 主机发送完 8 位数据

2. 主机释放 SDA（置高）

3. SCL=1 → 读取 SDA 电平
   
   - SDA=0 → ACK 成功
   - SDA=1 → NACK 失败

4. SCL=0 → 结束应答
   
   ## 
   
   ## 三、完整 I2C 主机发送时序（标准）
   
   ### <mark>起始信号(S) → 从机地址(7bit)+读写位(1bit) → ACK → 数据1 </mark>
   
   ### <mark> → ACK → 数据2 → ACK → ... → 停止信号(P)</mark>
   
   ##### 简单版：
   
   ##### **<mark>发起始 → 发地址 → 等ACK(ADDR) → 清标志 → 发数据 → 发停止</mark>**

### 关键细节：

#### 标志位清零方法：

        **读SR1 在读SR2**

```c
// 必须读 SR1 和 SR2 清除状态标志，否则硬件I2C卡死
  uint32_t temp = I2C1->SR1;
  temp = I2C1->SR2;
```

1. **从机地址**：7 位 + 1 位读写控制位
   
   - 读：`1` → 地址字节：`(addr<<1) | 1`
   - 写：`0` → 地址字节：`(addr<<1) | 0`

2. OLED 等从机设备**必须返回 ACK**，否则通信失败

3. 所有时序延时：根据 I2C 速率调整（100kHz≈5us，400kHz≈1.25us

### I2C配置流程（code）：

##### I2C1的引脚固定为 PB6 PB7

```c
/* 1。用外设先开时钟 */
void Clock_Init(void){
  // GPIOB
  RCC -> APB2ENR |= 1<<3;
  // AFIO
  RCC -> APB2ENR |= 1<<0;
  // 开I2C时钟
  RCC -> APB1ENR |= 1<<21;
  __DSB();
}

/* 2。配置要使用GPIO */
void GPIO_Init(void){
  // 清除原有配置 PA6 PA7
  GPIOB -> CRL &=~(0xF << 24);
  GPIOB -> CRL &=~(0xF << 28);

  // 配置为 复用开漏 
  GPIOB -> CRL |=(0x0F << 24);
  GPIOB -> CRL |=(0x0F << 28);
}

/*3.配置I2C*/
void User_I2C_Init(){
    // 1.复位I2C
    I2C1 -> CR1 |= 1<<15;
    I2C1 -> CR1 &=~(1<<15);

    // 2.设置时钟频率（APB1=36MHz）
    I2C1 -> CR2 = 36; // 内核频率36Mhz

    // 设置I2C速度 = 100kHz
    I2C1 -> CCR = 180; // 标准模式100kHz

    // 上升时间配置
    // TRISE 上升时间寄存器
    I2C1 -> TRISE = 37;

    // 开启I2C外设
    I2C1 -> CR1 |= 1<<0;
}

/* 
必须按照：
    发起始 → 发地址 → 等ACK(ADDR) → 清标志 → 发数据 → 发停止
 */

// 发送起始信号
void I2C_Start(void){
    I2C1 -> CR1 |= 1<<8; // 硬件起始
    while(!(I2C1 -> SR1 & (1<<0))); // 等待硬件起始成功
}

// 发地址 等ACK 清标志
void I2C_SendAddress_CleanFlag(uint8_t addr){
    I2C1 -> DR = addr; // 发地址

    //1.等待ADDR标志（地址发送完成 + 从机发送ACK）
    while(!(I2C1 -> SR1 &(1<<1)));

    // 2.必须读SR1 + SR2 清除ADDR标志
    volatile uint32_t temp = I2C1 -> SR1;
    temp = I2C1 -> SR2;
    (void)temp;
}

/* 发送一个字节的数据 */
void I2C_SendByte(uint8_t data){
  I2C1 -> DR = data;
  while(!(I2C1 -> SR1 & (1<<7)));  // 等待发送完成

  // 必须读 SR1 和 SR2 清除状态标志，否则硬件I2C卡死
  uint32_t temp = I2C1->SR1;
  temp = I2C1->SR2;
}

/* 发送停止信号 */
void I2C_Stop(void){
  I2C1 -> CR1 |= 1<<9;
}
```

### OLED接线：

- **VCC** → 3.3V
- **GND** → GND
- **SCL** → PB6
- **SDA** → PB7

### OLED的通用配置步骤

- 先 **关显示**
- 设置 **时钟**
- 设置 **分辨率 64 行**
- **开电荷泵（电源）**
- **开显示**

```plantext
// 1. 关屏（防乱闪）
0xAE

// 2. 配时钟（让芯片按100kHz I2C同步）
0xD5 → 0x80

// 3. 配尺寸（64行屏必须写0x3F）
0xA8 → 0x3F

// 4. 开电源（电荷泵，必开！否则不亮）
0x8D → 0x14

// 5. 开屏（配置完最后一步）
0xAF
```

```c
/* 向OLED中写命令 */
void OLED_WriteCmd(uint8_t cmd){
  I2C_Start();
  I2C_SendAddress(0x78);  // 从机地址
  I2C_SendByte(0x00);     // 0x00=命令标志
  I2C_Stop();
}

/* 向OLED中写数据 */
void OLED_WriteData(uint8_t data){
  I2C_Start();
  I2C_SendAddress(0x78);
  I2C_SendByte(0x40); // 0x40 = 数据标志位
  I2C_SendByte(data);      // 数据内容
  I2C_Stop();
}

/*初始化 OLED*/
void OLED_Init(void){
  HAL_Delay(100);  // 上电等稳定

  // 1.关闭显示 0xAE
  OLED_WriteCmd(0xAE);

  // 2.配置时钟
  OLED_WriteCmd(0xD5);
  OLED_WriteCmd(0x80);

  // 3.配置64行屏
  OLED_WriteCmd(0xA8);
  OLED_WriteCmd(0x3F);
  OLED_WriteCmd(0xA1);  // 列映射
  OLED_WriteCmd(0xC8);  // 行映射

  // 4.开电荷泵
  OLED_WriteCmd(0x8D);
  OLED_WriteCmd(0x14);

  // 5.打开显示
  OLED_WriteCmd(0xAF);
}
```

## 通信方向分类：全双工、半双工、单工

---

### 1. 单工（Simplex）

- **定义**：数据**只能单向传输**，发送方永远是发送方，接收方永远是接收方。

- **特点**：简单、无冲突、不需要方向切换。

- **举例**：
  
  - 广播电台（发射塔 → 收音机）
  
  - 传感器 → 单片机（仅输出，不接收命令）

- **STM32 中对应**：普通 GPIO 输出（如驱动 LED），或某些单线串行总线（如 1-Wire 在某些纯读场景）。

---

### 2. 半双工（Half-Duplex）

- **定义**：数据可以双向传输，但**不能同时**，收发分时共用一条信道。

- **特点**：需要切换方向、有总线冲突风险、协议需要避免碰撞。

- **举例**：
  
  - I2C（SDA 线双向分时复用）
  
  - 对讲机（说话时不能听，听时不能说话）
  
  - RS‑485（多节点共用差分线）

- **STM32 中对应**：模拟 I2C、硬件 I2C、单线 UART（半双工模式）。

---

### 3. 全双工（Full-Duplex）

- **定义**：数据可以**同时双向传输**，一般需要两条独立信道（一收一发）。

- **特点**：效率高、实时性好、硬件成本稍高（多一根线）。

- **举例**：
  
  - 电话（双方同时说话）
  
  - SPI（MOSI 与 MISO 独立）
  
  - 标准 UART（TX 与 RX 分开）

- **STM32 中对应**：SPI、UART（全双工模式）。
