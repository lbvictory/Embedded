## OLED 地址设置三句核心

1. **`0xB0 + page`**
   
   - 设置**页地址**，控制 “纵向在哪一行区域”
   - 一页 = 8 行，一共 8 页
   - 这是芯片规定的命令：`0xB0` 是第 0 页，`0xB1` 第 1 页……

2. **列地址分两次发：低 4 位 + 高 4 位**
   
   - 芯片规定：
   - 低 4 位命令格式：`0000 xxxx` → 所以从 0 列开始是 `0x00`
   - 高 4 位命令格式：`0001 xxxx` → 所以从 0 列开始是 `0x10`

    3. 这三条在一起 == "移动光标"

```c
OLED_WriteCmd(0xB0 + page);  // 第几行块
OLED_WriteCmd(0x00);         // 列低4位
OLED_WriteCmd(0x10);         // 列高4位
```

### 遇到问题 真正的高手怎么排查？

不是一眼看出，而是**按固定顺序扫**：

1. 功能不对？先看**数据 vs 命令**有没有写混
2. I2C 不通？先看**地址、应答、标志位清除**
3. 屏幕不亮？先看**电荷泵、方向配置、初始化顺序**
4. 显示乱码？先看**页地址、列地址**

### 先搞懂：字符是怎么显示的？

OLED 是**点阵屏**，一个字就是一堆 0/1 数据，叫**字模**。

我们用最常见的：

- **6×8 点阵**
  - 宽 6 列
  - 高 8 行（刚好占 1 页）
