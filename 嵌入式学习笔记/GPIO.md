# GPIO

## 常用的输入模式

### 0x00 模拟输入（ADC 专用）

### 0x04 浮空输入（默认、普通输入）

### 0x08 上拉/下拉输入（按键首选）

### // 通用输出（软件控制引脚）

### 0x03 通用推挽输出（LED、继电器、普通IO）

### 0x07 通用开漏输出（纯软件IO开漏，基本不用）

### // 复用外设输出（外设接管）

### 0x0B 复用推挽输出（PWM、UART_TX、SPI、TIM通道）

### 0x0F 复用开漏输出（硬件I2C SCL/SDA 专用）

STM32 规定了 GPIO 引脚的配置规则：每个引脚的 4 位里，前 2 位管 “模式”，后 2 位管 “速率”。

```planetext
4 位格式：[CNF1 CNF0] [MODE1 MODE0]
   前 2 位 → 模式
   后 2 位 → 速率
```

## GPIO四大寄存器：CRL/CRH/IDR/BSRR

### CRL/CRH

- PA0~7 → CRL
- PA8~15 → CRH
- 每个引脚 4 位
- 操作：先清空，再配置

操作 PA6 → 清空代码固定写：GPIOA->CRL &= ~(0xF << 24);
操作 PA0 → 清空代码固定写：GPIOA->CRL &= ~(0xF << 0);
（其他引脚：PAx → 0xF << (x×4)）

每个引脚占4个二进制为

#### IDR（Input Data Register，输入数据寄存器）

    只读：0 低电平 1 高电平
    寄存器位    0~15 位（低 16 位）    16~31 位（高 16 位）
    作用    对应 GPIO 引脚的实时输入电平（只读！）    保留位（无意义，永远为0）
    人话    「电平检测区」：读某一位的值，就能知道对应引脚当前是高电平还是低电平
    核心特点    只读寄存器 → 只能用「读」操作（GPIOA->IDR），
                不能写（比如 GPIOA->IDR = 1 << 6; 是错误的）
    GPIOA -> IDR &(1 << 0) 读取PA0的电平

#### **BSRR**

    寄存器位    0~15 位（低 16 位）    16~31 位（高 16 位）
    作用    置 1 → 引脚输出高    置 1 → 引脚输出低
    人话    点灯区    灭灯区
    
    GPIOA->BSRR = 1 << 6; → 亮

    GPIOA->BSRR = 1 << (6+16); → 灭

```c
GPIOA->BSRR = 1<<6;     // 置1
GPIOA->BSRR = 1<<(6+16); // 置0
```

    本质是：BSRR 寄存器分上下两半，上半区灭灯，下半区点灯

#### ODR 反转电平

// 反转PA6的电平

```c
GPIOA -> ODR ^= (1<<6);
```

## GPIO配置流程：

### 先清空--->再配置--->精准控制

✅ RCC 开时钟：RCC->APB2ENR |= 1 << 2;（给 GPIOA 供电）
✅ GPIO 配置流程：先清空（&= ~(0xF << 24)）→ 再配置（|= 0x3 << 24），精准控制 PA6 为输出模式
✅ BSRR 控电平：低 16 位第 n 位点灯（1<<n）、高 16 位第 n 位灭灯（1<<(n+16)），引脚和位号严格对应

上拉电阻：给引脚设置一个默认电平，避免悬空时电平乱跳（漂移）
 常用在：

1. 所有「机械按键 / 开关」输入
2. I2C 总线通信（必备）
3. SPI 总线（可选）
4. UART 串口（可选）
5. 传感器输入引脚

#### 上拉/下拉配置步骤

```c
// 1. 开时钟
RCC->APB2ENR |= 1<<2;

// 2. 清空4位
GPIOA->CRL &= ~(0xF << 0);

// 3. 设置为上拉/下拉输入模式 0x08
GPIOA->CRL |= (0x08 << 0);

// 4. 选择上拉 或 下拉
GPIOA->ODR |= (1<<0); // 上拉
GPIOA->ODR &= ~(1<<0); // 下拉
```

#### 按键配置四步走：

```
1.开始时钟：RCC->PAB2ENR |=1<<2;(PA0引脚，开GPIOA的时钟)
2.清空对应4位：GPIOA->CRL &=~(0xf << 0);
3.设为上拉输入：GPIOA->CRL &=~(0x8 << 0);
4.开上拉电阻：GPIOA->ODR |=(1 << 0);
    ODR 是32位寄存器，分高16位，低16位，高的是上拉电阻，低的是下拉电阻，对应引脚号（上拉：PA1 （1<<1）下拉 PA1（1<< (1+16)））
```

```c
// 1. 开时钟
RCC->APB2ENR |= 1<<2;

// 2. 清空4位
GPIOA->CRL &= ~(0xF << 0);

// 3. 设置上拉/下拉模式
GPIOA->CRL |= 0x08 << 0;

// 4. 开启上拉
GPIOA->ODR |= 1<<0;
```

推挽：自己能出高电平 → 点灯用
开漏：自己出不了高电平 → 通信用

# 推挽 开漏 通用 复用

## **GPIO 输出模式 = 2 种电路结构 × 2 种控制来源 = 一共 4 种！**

- **电路结构**：推挽 / 开漏
- **控制来源**：通用（软件） / 复用（外设）
  所以：
  **4 种输出模式 = 推挽2种 + 开漏2种**

---

## 一、先讲 2 种**电路结构**（本质区别）

## 1. 推挽输出（Push-Pull）

### 人话：

**既能强行输出高电平，也能强行输出低电平！**

### 结构：

- 上MOS管：输出 **高电平（3.3V）**

- 下MOS管：输出 **低电平（0V）**
  
  ### 优点：

- 驱动能力强

- 速度快

- 不用外部上拉电阻
  
  ### 缺点：

- **不能和其他输出短接！会烧芯片！**

---

## 2. 开漏输出（Open-Drain）

### 人话：

**只能输出低电平，不能输出高电平！**
**高电平必须靠外部上拉电阻！**

### 结构：

- 只有下MOS管：只能拉低

- 高电平 = 外部电阻拉上去
  
  ### 优点：

- 支持**线与**（多个设备共总线）

- 支持**电平变换**（3.3V ↔ 5V）

- I2C 必须用它
  
  ### 缺点：

- 没上拉电阻就无法通信

---

## 二、再讲 2 种**控制来源**

## 1. 通用输出（GPIO）

### 人话：

**你自己用代码控制引脚（BSRR/ODR）**

- LED

- 继电器

- 模拟I2C

- 任意自己写的电平
  
  ## 2. 复用输出（Peripheral）
  
  ### 人话：
  
  **外设接管引脚，CPU 不管了！**

- PWM

- UART_TX

- SPI

- 硬件I2C

---

## 三、4 种输出模式 **完整版讲解**

---

## 模式 1：**通用推挽输出（0x03）**

## 二进制：0011

## 定义：

软件控制 + 推挽电路

## 能干什么：

- 输出强高

- 输出强低
  
  ## 用途：
  
  **LED、蜂鸣器、继电器、普通IO**
  
  ## 你写的代码：
  
  ```c
  GPIOx->CRL |= 0x03 << n;
  ```

---

## 模式 2：**复用推挽输出（0x0B）**

## 二进制：1011

## 定义：

外设控制 + 推挽电路

## 能干什么：

- 外设输出强高/强低

- CPU 不干预
  
  ## 用途：
  
  **PWM、串口TX、SPI、定时器通道**
  
  ## 代码：
  
  ```c
  GPIOx->CRL |= 0x0B << n;
  ```

---

## 模式 3：**通用开漏输出（0x07）**

## 二进制：0111

## 定义：

软件控制 + 开漏电路

## 能干什么：

- 软件拉低

- 高靠上拉
  
  ## 用途：
  
  **模拟I2C（软件I2C）**
  
  ## 代码：
  
  ```c
  GPIOx->CRL |= 0x07 << n;
  ```

---

## 模式 4：**复用开漏输出（0x0F）**

## 二进制：1111

## 定义：

外设控制 + 开漏电路

## 能干什么：

- 硬件外设拉低

- 高靠上拉
  
  ## 用途：
  
  **硬件 I2C SCL/SDA 唯一正确模式**
  
  ## 代码：
  
  ```c
  GPIOx->CRL |= 0x0F << n;
  ```

---

## 四、终极总结表

## **4 种输出模式完整版**

```
1. 0x03 通用推挽 软件控制、推挽、强高强低
 → LED、普通IO
2. 0x0B 复用推挽 外设控制、推挽、强高强低
 → PWM、UART、SPI、TIM
3. 0x07 通用开漏 软件控制、开漏、只能拉低
 → 模拟I2C（软件I2C）
4. 0x0F 复用开漏 外设控制、开漏、只能拉低
 → 硬件I2C（唯一正确）
```

---

## 五、最简单记忆法

## 看第一位：

- **0xxx → 通用（软件控制）**

- **1xxx → 复用（外设控制）**
  
  ## 看第二位：

- **x0xx → 推挽**

- **x1xx → 开漏**
  
  ## 最后两位固定：

- **xx11 → 输出模式 50MHz（永远用这个）**

---

## 六、你以后怎么选模式？

### 1. 点灯 → 0x03

### 2. PWM → 0x0B

### 3. 软件I2C → 0x07

### 4. 硬件I2C → 0x0F

---

## 七、最终结论

## **推挽 = 能高强低**

## **开漏 = 只能拉低**

## **通用 = 你代码控制**

## **复用 = 外设自己控制**
