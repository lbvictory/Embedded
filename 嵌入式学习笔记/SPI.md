# SPI

#### **SPI 就是主机通过 CS 选中从机，然后按 SCK 节拍，在 MOSI 上发数据的同时从 MISO 上收数据，8 个节拍完成一字节交换。**

```c
void SPI1_Init(void)
{
    // 1. 开时钟
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;   // GPIOA
    RCC->APB2ENR |= RCC_APB2ENR_SPI1EN;   // SPI1
    __DSB();

    // 2. 配置 GPIO
    // PA5 SCK - 复用推挽 0xB
    GPIOA->CRL &= ~(0xF << 20);
    GPIOA->CRL |=  (0xB << 20);

    // PA7 MOSI - 复用推挽 0xB
    GPIOA->CRL &= ~(0xF << 28);
    GPIOA->CRL |=  (0xB << 28);

    // PA6 MISO - 浮空输入 0x4
    GPIOA->CRL &= ~(0xF << 24);
    GPIOA->CRL |=  (0x4 << 24);

    // PA4 CS - 通用推挽输出 0x3（软件控制）
    GPIOA->CRL &= ~(0xF << 16);
    GPIOA->CRL |=  (0x3 << 16);
    GPIOA->ODR |= (1 << 4);   // CS默认高

    // 3. SPI 软件复位（可选，但建议）
    SPI1->CR1 = 0;

    // 4. 配置 SPI
    SPI1->CR1 = 0;                    // 先清零
    SPI1->CR1 |= (1 << 2);            // Master主机模式
    SPI1->CR1 |= (0 << 1) | (0 << 0); // 模式0：CPOL=0, CPHA=0
    SPI1->CR1 |= (2 << 3);            // BR波特率 /8 = 9MHz(72/8)
    SPI1->CR1 |= (0 << 7);            // MSB First（高位先行）
    SPI1->CR1 |= (0 << 11);           // 8位数据帧

    // 5. 软件管理NSS（不用硬件CS）
    SPI1->CR1 |= (1 << 9);            // SSM=1 软件管理
    SPI1->CR1 |= (1 << 8);            // SSI=1 内部NSS高

    // 6. 使能 SPI
    SPI1->CR1 |= (1 << 6);
}
```

## 📊 BR 位（SPI_CR1 的 Bit3~Bit5）分频表

| BR 位值 (二进制) | 分频系数 | SPI 时钟频率 (PCLK=72MHz) | 配置写法 (`SPI1->CR1` 中的代码)   |
| ----------- | ---- | --------------------- | ------------------------- |
| `000`       | 2    | 36 MHz                | `SPI1->CR1 \|= (0 << 3);` |
| `001`       | 4    | 18 MHz                | `SPI1->CR1 \|= (1 << 3);` |
| `010`       | 8    | 9 MHz (常用)            | `SPI1->CR1 \|= (2 << 3);` |
| `011`       | 16   | 4.5 MHz               | `SPI1->CR1 \|= (3 << 3);` |
| `100`       | 32   | 2.25 MHz              | `SPI1->CR1 \|= (4 << 3);` |
| `101`       | 64   | 1.125 MHz             | `SPI1->CR1 \|= (5 << 3);` |
| `110`       | 128  | 562.5 kHz             | `SPI1->CR1 \|= (6 << 3);` |
| `111`       | 256  | 281.25 kHz            | `SPI1->CR1 \|= (7 << 3);` |

## 遇到 SPI 问题，直接按这个顺序排查：

1. **接线与供电：共地了吗？设备供电正常吗？线没焊反 / 虚焊吗？**
2. 信号存在性：CS/SCK/MOSI/MISO 都有波形吗？
3. 模式匹配：CPOL/CPHA、位序（MSB/LSB）和从机一致吗？
4. 时序稳定性：时钟频率是不是太快？建立 / 保持时间够吗？
5. 数据正确性：主机发的指令 / 地址对不对？从机返回的数据和预期一致吗？

## 简化的W25Q64模块接线

## ✅ 你的模块接线（6脚版）

| 模块引脚          | 接 STM32  |
| ------------- | -------- |
| **VCC**       | **3.3V** |
| **CS**        | **PA4**  |
| **DO** (MISO) | **PA6**  |
| **GND**       | **GND**  |
| **CLK**       | **PA5**  |
| **DI** (MOSI) | **PA7**  |

**命名对应**：

- `DO` = Data Out = MISO（W25Q64输出→STM32）

- `DI` = Data In = MOSI（STM32→W25Q64）

- `SLK`  SCK

### GPIO通用配置规则

| 引脚       | 功能方向       | GPIO 模式 | 输出速度  | 上下拉    | 寄存器配置值 (4位)     |
| -------- | ---------- | ------- | ----- | ------ | --------------- |
| **CS**   | 输出（主机控制）   | 通用推挽输出  | 50MHz | 无      | `0x3` (CRL/CRH) |
| **SCK**  | 输出（主机提供时钟） | 复用推挽输出  | 50MHz | 无      | `0xB` (CRL/CRH) |
| **MOSI** | 输出（主机发数据）  | 复用推挽输出  | 50MHz | 无      | `0xB` (CRL/CRH) |
| **MISO** | 输入（主机收数据）  | 浮空输入    | N/A   | 无（或上拉） | `0x4` (CRL/CRH) |

- **CS 是通用推挽**：因为 SPI 硬件不自动控制 CS，需软件拉高/拉低。

- **SCK 和 MOSI 是复用推挽**：因为这些引脚由 SPI 外设接管，不再由普通 GPIO 输出寄存器控制。

- **MISO 是浮空输入**：不需要上拉（SPI 从机驱动 MISO 线）。如果总线有长线干扰，也可配置为上拉输入 `0x8`，但标准是浮空。

## SPI通信协议

### 概念：

    **SPI 是一种同步、全双工、主从式的串行通信协议。下面用最简方式讲清楚。**

### 1.四更信号线

| 信号       | 方向  | 含义              |
| -------- | --- | --------------- |
| **SCK**  | 主→从 | 时钟，由主机产生，决定传输速率 |
| **MOSI** | 主→从 | 主机输出，从机输入（数据线）  |
| **MISO** | 从→主 | 从机输出，主机输入（数据线）  |
| **CS**   | 主→从 | 片选，低电平选中指定从机    |

**形象理解**：

- SCK = 节拍器（主机打拍子）

- MOSI = 主机说话，从机听

- MISO = 从机说话，主机听

- CS = 喊名字（选中哪个设备）

### 2.通信过程（一次完成交换）

1. **主机拉低 CS** → 选中某个从机

2. **主机产生 SCK 脉冲**（每个脉冲传输 1 bit）

3. **同时进行**：
   
   - 主机在 MOSI 线上发送 1 bit
   
   - 从机在 MISO 线上发送 1 bit

4. 重复 8 次 → 完成 1 字节交换

5. **主机拉高 CS** → 结束通信 

**关键点**：收发是**同时完成**的。每发 1 bit 的同时，也会收到 1 bit。

### 3. 四种模式（由 CPOL 和 CPHA 决定）

- **CPOL**：时钟极性（空闲时 SCK 电平）
  
  - `0`：空闲低
  
  - `1`：空闲高

- **CPHA**：时钟相位（数据采样时刻）
  
  - `0`：在 SCK 第一个边沿采样
  
  - `1`：在 SCK 第二个边沿采样

| 模式  | CPOL | CPHA | 说明（最常用模式0） |
| --- | ---- | ---- | ---------- |
| 0   | 0    | 0    | 空闲低，上升沿采样  |
| 1   | 0    | 1    | 空闲低，下降沿采样  |
| 2   | 1    | 0    | 空闲高，下降沿采样  |
| 3   | 1    | 1    | 空闲高，上升沿采样  |

**你的代码配置**：模式0（CPOL=0, CPHA=0）

- 空闲时 SCK = 0

- 数据在**上升沿**被采样
