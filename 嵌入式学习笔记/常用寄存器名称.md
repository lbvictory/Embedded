### CR

**TIMx_CR1** 是**定时器的控制寄存器1 (Control Register 1)**，用于配置定时器的核心工作模式。

**主要配置位包括**：

- **位0 (CEN)**：计数器使能 (0=关闭, 1=开启)

- **位4-6 (DIR, CMS)**：计数方向选择 (向上/向下/中心对齐)

- **位7 (ARPE)**：自动重装载预装载使能 (0=立即更新, 1=等待事件更新)

### TRISE

**I2C_TRISE** 是 **上升时间寄存器 (Rise Time Register)**。

**作用**：

- 配置SCL/SDA线上升沿的**最大允许时间**（以周期为单位）
- 用于I2C总线滤波，防止信号过陡

**计算公式**：

- 标准模式 (100kHz)：`TRISE = 最大上升时间(ns) / 周期(ns) + 1`
- 快速模式 (400kHz)：`TRISE = 300ns / 周期(ns) + 1`

**例中 37**：

- 若APB1时钟 = 36MHz → 周期 ≈ 27.8ns
- `300ns / 27.8ns + 1 ≈ 10.8 + 1 ≈ 12`（实际应为12左右）
- 37意味着时钟频率较低（如APB1=8MHz时周期125ns，`300/125+1≈3.4`，仍不符）

**常见值**：标准模式通常设 **TRISE=17~20**，快速模式设 **TRISE=4~12**。37可能因时钟较低导致。

SR1

**I2C_SR1** 是 **状态寄存器1 (Status Register 1)**，用于指示I2C通信状态和错误标志。

**常用位**：

- **位0 (SB)**：起始位已发送 (Start Bit)
- **位1 (ADDR)**：地址已发送/匹配 (Address sent/match)
- **位2 (BTF)**：字节传输完成 (Byte Transfer Finished)
- **位3 (ADD10)**：10位地址头已发送
- **位4 (STOPF)**：停止位检测 (Stop flag)
- **位6 (TxE)**：数据寄存器空 (Transmit empty)
- **位7 (RxNE)**：数据寄存器非空 (Receive not empty)
- **位8-9**：总线错误、仲裁丢失等错误标志

**典型用法**：

```c
while(!(I2C1->SR1 & (1<<7)));  // 等待RxNE置位
data = I2C1->DR;                // 读取数据后自动清除标志
```
